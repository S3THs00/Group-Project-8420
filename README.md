# CYBR 8420 – OpenEMR Security Enhancement Project

## Project Overview

This repository contains our team's CYBR 8420 group project focused on analyzing and enhancing the security of the OpenEMR open-source electronic health record system.

Our team is evaluating OpenEMR from a software assurance and systems security engineering perspective, with particular attention to authentication security and multi-factor authentication (MFA).

## Open-Source Project

**OpenEMR**

OpenEMR is an open-source electronic health record (EHR) and medical practice management system.

## Proposed Security Focus

Our team is investigating OpenEMR's existing authentication architecture and multi-factor authentication capabilities to identify an appropriate security enhancement that can be implemented and evaluated as part of the project.
